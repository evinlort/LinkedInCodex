# Local source documents

This directory may contain the private PDF sources used to curate the runtime
profile. PDF files and `linkedin_profile_url.txt` are intentionally ignored by
Git. They are not read at runtime.

Source precedence is:

1. Master Career and Skills Profile v2.
2. The current general CV for non-conflicting additional evidence.
3. Later facts explicitly verified by the profile owner.

The LinkedIn profile is not a skill source. In particular, the obsolete joke
entries `AWS Infinidash` and `python :) (Professional Working)` must never be
imported as evidence.
